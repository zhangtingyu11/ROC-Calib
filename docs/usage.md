# 使用方法

启动 `./start.sh`，打开 http://localhost:3000。

## 先试示例

点击首页的 **打开 CARLA 示例**。首次下载约 56 MiB，随后会载入 19 帧数据和 20 对标注。

![工作台](assets/workspace.png)

## 标定自己的数据

1. **新建组**：同一组中的帧应共用一套固定外参。
2. **添加数据**：导入 ROS2 SQLite bag，或选择已配对的图像和点云目录。目录格式见[数据格式](data.md)。
3. **检查内参**：确认分辨率、畸变模型和内参对应当前图像。已经去畸变的图像应使用去畸变后的内参。
4. **保存配对**：在点云中选择一个物体，在图像中标出同一物体。可使用 SAM 框选，再用画笔增删。点击“保存配对”。
5. **计算外参**：选择“无初值 PnP”，点击“计算外参”。计算使用当前相机模型。
6. **检查并导出**：浏览不同帧，检查投影，再导出 JSON。标注改动后，“待重算”表示当前结果对应旧标注。

选取位置、距离和方向分布不同的物体。避免只选择共线、同一小区域或正在独立运动的物体。论文每组使用 20–30 对；少量配对能否求解取决于几何分布。

## 常用操作

| 操作 | 入口 |
| --- | --- |
| 切换数据、传感器、投影模型 | 左上角菜单 |
| 修改图像区域 | SAM 替换/追加、画笔添加/擦除 |
| 修改点云区域 | 框选聚类、单点聚类、画笔添加/删除 |
| 查看已保存配对 | 上方配对列表 |
| 比较两个外参版本 | 外参对比 |
| 检查可疑配对 | 配对复查 |

配对复查中的结构提取和联合拟合属于实验工具，不属于论文的区域目标求解流程。

## 保存与输出

标注自动同步到当前服务器任务组。顶部显示同步状态；失败时可重试或下载当前标注备份。另一窗口已修改同一组时，先备份本地编辑，再刷新。

导出矩阵满足 `p_camera = T_camera_from_lidar @ p_lidar`，采用列向量、行优先存储，平移单位为米。相机坐标轴为右、下、前。点云坐标轴沿用输入定义。

删除的组移到 `data/trash/`。恢复时停止服务，将对应目录移回 `data/groups/` 并恢复原目录名。

## English quick reference

**新建组**: new group · **添加数据**: add data · **导入内参**: import intrinsics · **保存配对**: save pair · **计算外参**: calibrate · **外参对比**: compare poses · **导出当前包结果**: export.

The workbench currently uses Chinese labels. Start with the CARLA example, then follow the same import → match → calibrate → inspect → export workflow for your data.
